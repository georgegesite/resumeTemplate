# resume
LaTeX template for my personal resume

Based off of [jakegut/resume](https://github.com/jakegut/resume)
Use it on overleaf: [Jake's Resume](https://www.overleaf.com/latex/templates/jakes-resume/syzfjbzwjncs) (Not updated)

Download MikTex
To confirm if miktex is installed `miktex --version`
To convert .tex file to PDF `pdflatex resume.tex`
